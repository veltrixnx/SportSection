# Спортивна секція — лабораторна 10

Консольний проєкт C# для додавання й перегляду вихованців. Для кожного поля використовується окремий масив на 100 записів; номер призначається автоматично.

## Запуск

Відкрийте `SportSectionLab10.csproj` у Rider або виконайте в цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.

## Можливості

- Пункт 1 показує заповнені записи таблицею, їхню кількість і розподіл за віковими групами.
- Пункт 2 додає вихованця після перевірки введених полів; при повному сховищі додавання неможливе.
- Пункт 10 додає шість готових записів, якщо для всіх є місце.
- Код виду спорту поки вводиться числом: довідник з'явиться в лабораторній 12. Пункти майбутніх робіт повідомляють, що функцію ще не реалізовано.
- Вік для розподілу приблизний: поточний рік мінус рік народження. Групи для цієї роботи: до 12, 12–17, 18 років і старші; у завданні їхні межі не задані.
- Записи зберігаються в пам'яті до завершення програми. Збереження у файл передбачене в лабораторній 15.
