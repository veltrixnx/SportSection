# Спортивна секція — лабораторна 9

Окремий консольний проєкт C# про масиви, параметри `ref` і `out`, видалення елементів та роботу з одним спільним масивом.

## Запуск у Rider

Відкрийте файл `SportSectionLab9.csproj` у Rider і натисніть **Run**. Для запуску потрібен .NET 10 SDK.

Також проєкт можна запустити з термінала, перебуваючи в цій папці:

```bash
dotnet run
```
