# Спортивна секція — лабораторна 9

Окремий консольний проєкт C# про масиви, параметри `ref` і `out`, видалення елементів та роботу з одним спільним масивом.

## Запуск у Rider

Відкрийте файл `SportSectionLab9.csproj` у Rider і натисніть **Run**. Для запуску потрібен .NET 10 SDK.

Також проєкт можна запустити з термінала, перебуваючи в цій папці:

```bash
dotnet run
```

## Що реалізовано

- у `Main` створюється масив `double` на 100 елементів і лічильник `count`;
- початкові та додаткові значення вводяться в `Main`, а метод `AddValues` отримує лічильник через `ref`;
- `PrintValues` виводить заповнену частину масиву з номерами й не читає клавіатуру;
- `FindMaximum` повертає найбільше значення й його номер через два `out`-параметри та окремо обробляє порожній масив;
- `RemoveAt(double[] values, ref int count, int index)` видаляє елемент, зсуває решту значень і зменшує лічильник; неправильний номер не змінює масив;
- меню працює з тим самим масивом для додавання, видалення, перегляду та статистики;
- окремий пункт показує, що `int` передається за значенням, а зміна елемента масиву видима після повернення з методу.

У меню номери елементів починаються з 1. Усередині масиву індексація починається з 0.
