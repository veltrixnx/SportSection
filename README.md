# Спортивна секція

Консольний застосунок об'єднує роботу над проєктом у лабораторних 7–11. Код розміщено у файлі `Program.cs`.

## Запуск

Відкрийте `SportSection.csproj` у Rider або виконайте в цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.

## Головне меню

- **1 — Основна програма:** облік вихованців із лабораторних 10–11. Можна додавати й переглядати записи, шукати, змінювати й видаляти їх, додавати готові приклади та переглядати підсумки.
- **2 — Довідка і таблиці:** вправи лабораторної 7.
- **3 — Довідка і таблиці з методами:** вправи лабораторної 8.
- **4 — Вправи з масивом:** лабораторна 9.
- **0 — Вихід.**

В основній програмі пункти 6–9 і 11 призначені для наступних лабораторних. Вона зберігає до 100 вихованців у паралельних масивах оперативної пам'яті. Дані не зберігаються після виходу з основної програми.

Підсумки показують кількість записів, розподіл за віковими групами та найменшу, найбільшу й середню кількість тренувань на тиждень. Вік визначається приблизно: поточний рік мінус рік народження. Використано групи до 12, 12–17 і 18 років та старші.

Попередні версії проєкту доступні в історії комітів репозиторію.
