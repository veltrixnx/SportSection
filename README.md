# Спортивна секція

Навчальний консольний проєкт на C# для Rider на macOS. Це початковий каркас наскрізного проєкту для варіанта 12.

## Запуск у Rider

1. Відкрийте `SportSection.csproj` у Rider.
2. Виберіть конфігурацію запуску `SportSection` і натисніть Run.

Також можна запустити з термінала в цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.

## Реалізовано в першій лабораторній

- меню в циклі з трьома робочими пунктами й виходом;
- довідка про тему, головну сутність і типи її полів;
- таблиця вартості тренування залежно від тривалості, з дробовим кроком 0,5 години й десятьма рядками;
- зведена таблиця «вікова група × вид спорту» (від 1 до 20 рядків і стовпців) з підсумками рядків, стовпців і загальним підсумком;
- перевірка неправильного пункту меню та введених чисел;
- пауза й очищення екрана після кожної дії.
