# Спортивна секція — лабораторна 11

Консольна програма продовжує лабораторну 10: обліковує вихованців у паралельних масивах фіксованої довжини та підтримує додавання, перегляд, пошук, зміну й видалення записів.

## Запуск

Відкрийте `SportSectionLab11.csproj` у Rider або виконайте у цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.

## Пункти меню

- **1 — показати всіх вихованців:** таблиця, кількість записів і розподіл за віковими групами.
- **2 — додати вихованця:** перевірка полів і автоматичне призначення номера.
- **3 — знайти запис:** за частиною прізвища або імені чи за діапазоном років народження. Текстовий пошук чутливий до регістру; межі числового діапазону включні.
- **4 — змінити запис:** пошук за номером, показ поточних значень; порожній Enter зберігає поле. Номер не змінюється.
- **5 — видалити запис:** підтвердження та зсув усіх паралельних масивів; номери решти вихованців не змінюються.
- **10 — додати шість готових записів:** якщо достатньо місця, вони додаються до наявних.
- **12 — підсумки:** кількість і розподіл за віковими групами; найбільша, найменша й середня кількість тренувань на тиждень. Для найбільшого й найменшого значень показано номери вихованців.
- **0 — вихід.** Пункти 6–9 і 11 призначені для наступних лабораторних.
