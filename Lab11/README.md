# Спортивна секція — лабораторна 11

Консольна програма продовжує лабораторну 10: обліковує вихованців у паралельних масивах фіксованої довжини та підтримує додавання, перегляд, пошук, зміну й видалення записів.

## Запуск

Відкрийте `SportSectionLab11.csproj` у Rider або виконайте у цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.
