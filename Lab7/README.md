# Спортивна секція

Навчальний консольний проєкт на C# для Rider на macOS. Це початковий каркас наскрізного проєкту для варіанта 12.

## Дані предметної області

Головна сутність майбутньої системи — вихованець спортивної секції. Один запис має такі поля:

| Поле | Тип | Призначення |
|---|---|---|
| Номер | `int` | Унікальний номер, який призначає програма |
| Прізвище та ім’я | `string` | Ім’я вихованця |
| Рік народження | `int` | Рік народження вихованця |
| Код виду спорту | `int` | Посилання на запис у довіднику видів спорту |
| Спортивний розряд | `string` | Розряд вихованця |
| Дата вступу | `DateTime` | Дата зарахування до секції |
| Тренувань на тиждень | `int` | Кількість тренувань вихованця |

Для майбутнього введення плануються перевірки: ім’я не порожнє, рік народження лежить у межах від 1900 року до поточного, дата коректна й не з майбутнього, а код виду спорту відповідає наявному запису довідника. Лабораторна програма показує структуру сутності у довідці, але ще не зберігає записи вихованців.

## Запуск у Rider

1. Відкрийте `SportSection.csproj` у Rider.
2. Виберіть конфігурацію запуску `SportSection` і натисніть Run.

Також можна запустити з термінала в цій папці:

```bash
dotnet run
```

Потрібен .NET 10 SDK.

## Реалізовано в першій лабораторній

- меню в циклі з трьома робочими пунктами й виходом;
- довідка про тему, головну сутність і типи її полів;
- таблиця вартості тренування залежно від тривалості, з дробовим кроком 0,5 години й десятьма рядками;
- зведена таблиця «вікова група × вид спорту» (від 1 до 20 рядків і стовпців) з підсумками рядків, стовпців і загальним підсумком;
- перевірка неправильного пункту меню та введених чисел;
- пауза й очищення екрана після кожної дії.

## Приклади для демонстрації

- У пункті 2 введіть ціну `200` грн за годину й початкову тривалість `1` година. У таблиці буде 10 рядків із кроком 0,5 години; перші вартості — 200 і 300 грн.
- У пункті 3 введіть 2 вікові групи та 2 види спорту. Для значень 8, 12, 3 і 4 підсумки рядків будуть 20 і 7, підсумки стовпців — 11 і 16, загальний підсумок — 27.
- Якщо для кількості рядків або стовпців ввести 0, програма повідомить про помилку й повернеться до меню без побудови таблиці.
